# Spec Delta

## Purpose

Библиотека стратегий атаки: версионные техники с условиями применения и статистикой успеха,
ранжированный поиск по области и обучение по исходу эпизода.

## ADDED Requirements

### Requirement: Ранжированный поиск стратегий по области

Библиотека SHALL возвращать стратегии, релевантные запросу, с обязательным фильтром области
(ветки). Стратегии чужой области MUST NOT возвращаться.

#### Scenario: Релевантная стратегия своей области возвращается, чужой — нет

- **WHEN** выполняется поиск стратегий в области A по запросу
- **THEN** возвращаются ранжированные стратегии области A, а стратегии области B отсутствуют

### Requirement: Обучение по исходу

Статистика стратегии SHALL обновляться по исходу её применения (успех/неуспех). При равной
релевантности стратегия с большей долей успеха MUST ранжироваться выше.

#### Scenario: Успешная стратегия поднимается в ранжировании

- **WHEN** у двух равно релевантных стратегий разная доля успеха
- **THEN** стратегия с большей долей успеха возвращается раньше
