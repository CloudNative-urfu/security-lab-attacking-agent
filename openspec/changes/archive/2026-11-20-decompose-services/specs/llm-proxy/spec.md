# Spec Delta

## ADDED Requirements

### Requirement: Сетевой транспорт модели за портом LLMClient

Транспорт к модели SHALL быть доступен как сетевой сервис через реализацию порта
`LLMClient`. Одна успешная обработка запроса шлюзом MUST соответствовать одной физической
отправке; скрытые retry/fallback на уровне шлюза MUST быть выключены.

#### Scenario: Вызов через сетевой LLMClient даёт одну отправку

- **WHEN** домен вызывает модель через сетевой `LLMClient` (HTTP-шлюз)
- **THEN** шлюз выполняет ровно одну физическую отправку и возвращает нормализованный ответ
