# Spec Delta

## ADDED Requirements

### Requirement: Проверка адреса на момент соединения

Проверка адреса SHALL выполняться на момент фактического соединения, а не только заранее,
чтобы исключить подмену разрешения имени между проверкой и запросом (DNS rebinding/TOCTOU).
Каждый фактический запрос и редирект проходит повторную проверку по текущему разрешённому IP.

#### Scenario: Смена разрешения имени между проверкой и запросом блокируется

- **WHEN** имя, прошедшее предварительную проверку, на момент соединения резолвится во
  внутренний (запрещённый) адрес
- **THEN** соединение запрещается
