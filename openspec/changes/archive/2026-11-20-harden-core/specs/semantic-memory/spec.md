# Spec Delta

## ADDED Requirements

### Requirement: Ранжирующий поиск вместо подстроки

Reader SHALL ранжировать результаты по релевантности запросу (например, перекрытие
токенов/BM25-подобный скоринг либо эмбеддинги через порт), а не фильтровать простым
вхождением подстроки. Фильтр области остаётся обязательным для всех путей.

#### Scenario: Более релевантная запись ранжируется выше

- **WHEN** несколько записей области совпадают по разным термам запроса
- **THEN** запись с большим перекрытием термов возвращается раньше менее релевантной

### Requirement: Реальная оценка кандидата при публикации

Оценка кандидата SHALL проверять согласованность состава (scope, base_version, read_set,
hash) и обязательный набор критериев, а не безусловно подтверждать. Несогласованный кандидат
MUST получать отрицательный вердикт.

#### Scenario: Несогласованный состав получает отрицательную оценку

- **WHEN** оценивается кандидат с базой, не совпадающей с текущей версией ветки
- **THEN** вердикт оценки отрицательный (кандидат не одобрен к публикации)
