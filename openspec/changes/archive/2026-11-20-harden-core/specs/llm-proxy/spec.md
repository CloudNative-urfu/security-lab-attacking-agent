# Spec Delta

## ADDED Requirements

### Requirement: Durable журнал попыток модели

LLM Proxy SHALL вести durable журнал по (op_id, attempt_id). Повторная обработка той же
попытки MUST возвращать записанный ответ без нового физического вызова провайдера; новый
физический вызов требует новой попытки (attempt_id) и нового допуска.

#### Scenario: Повтор попытки не вызывает модель повторно

- **WHEN** proxy.request обрабатывается повторно с тем же (op_id, attempt_id)
- **THEN** возвращается ранее записанный ответ, а провайдер не вызывается второй раз
