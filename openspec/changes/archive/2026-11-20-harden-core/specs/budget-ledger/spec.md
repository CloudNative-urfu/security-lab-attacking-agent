# Spec Delta

## ADDED Requirements

### Requirement: Кросс-процессная сериализация бюджета

Резерв и расчёт SHALL быть защищены блокировкой на уровне БД, удерживающей инвариант
жёсткого лимита между независимыми процессами (воркерами), а не только потоками одного
процесса. На SQLite это `BEGIN IMMEDIATE`; на PostgreSQL — row lock (`SELECT … FOR UPDATE`)
или advisory lock по счёту.

#### Scenario: Конкурентные резервы не превышают жёсткий лимит

- **WHEN** несколько конкурентных операций пытаются зарезервировать сверх остатка жёсткого бюджета
- **THEN** суммарно подтверждается не больше остатка; лишние получают NO_BUDGET
