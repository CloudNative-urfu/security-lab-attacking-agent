# Spec Delta

## ADDED Requirements

### Requirement: Планировщик использует стратегии как доверенную подсказку

Контроллер эпизода SHALL извлекать релевантные стратегии из библиотеки и включать их в
контекст модели как ДОВЕРЕННУЮ секцию (отдельно от недоверенных наблюдений СС). Отсутствие
библиотеки MUST сохранять прежнее поведение.

#### Scenario: Релевантные стратегии попадают в контекст решения

- **WHEN** в библиотеке есть релевантные стратегии для вопроса шага
- **THEN** они включены в доверенную часть запроса к модели, отдельно от блока данных СС
