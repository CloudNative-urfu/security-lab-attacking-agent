# Proposal

## Why

В карте компонентов есть «Исследующий агент для СС», которого не было в реализации: он
анализирует СС и готовит черновик КИК для утверждения оператором. Без него КИК собирается
вручную. Это отдельный привилегированный контекст подготовки, который НЕ расширяет
полномочия атакующего и имеет собственный бюджет.

## What Changes

- Вводится доменный `research-agent`: из базовой информации о СС и доступных интерфейсов
  формирует типизированный **черновик КИК** (objective/target/interfaces/budgets/policy)
  через LLM-предложение с валидацией.
- Приватные исходники/внутренние guardrails и admin-данные НЕ переносятся в контекст
  атакующего (только публичная проекция).
- Собственный конечный бюджет подготовки (отдельно от бюджета кампании).
- Утверждение оператором → freeze → неизменяемая КИК.

## Capabilities

### New Capabilities

- `research-agent`: подготовка черновика КИК по СС с валидацией и утверждением оператором.

## Impact

- Новый пакет `attacking_agent/domain/research`; переиспользует config/llm/budget.
