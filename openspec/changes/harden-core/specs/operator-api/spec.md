# Spec Delta

## ADDED Requirements

### Requirement: Токены со сроком и областью

Авторизация SHALL принимать только токены с проверяемой целостностью, сроком действия
(`exp`) и областью (`scope`). Просроченный или не покрывающий требуемую область токен MUST
отклоняться; литеральное сравнение строк недопустимо как единственный механизм.

#### Scenario: Просроченный токен отклоняется

- **WHEN** предъявляется токен с истёкшим `exp`
- **THEN** доступ отклоняется (401/403)

#### Scenario: Токен без нужной области отклоняется

- **WHEN** токен не содержит области, требуемой эндпойнтом
- **THEN** доступ отклоняется

### Requirement: Устойчивая редакция секретов

Редакция секретов в экспортах SHALL обнаруживать секреты и по значению (характерные шаблоны
и высокая энтропия), а не только по имени поля, и MUST применять совпадение по границам слов,
чтобы не вырезать безобидные поля и не пропускать секреты в нейтрально названных полях.

#### Scenario: Секрет в нейтрально названном поле вырезается

- **WHEN** экспорт содержит токеноподобное значение в поле без «секретного» имени
- **THEN** значение не попадает в выгрузку
